



# ⌨️ AutoTyper

**AutoTyper** — утилита для автоматической эмуляции ручного ввода текста с клавиатуры на уровне системы (Windows API).

Создана специально для обхода ограничений на веб-сайтах, в тестирующих системах, удаленных рабочих столах (RDP), экзаменационных платформах и терминалах, **где программно заблокирована вставка из буфера обмена (`Ctrl+V`)**.

## ✨ Ключевые возможности

- **Обход блокировок вставки:** Ввод осуществляется через низкоуровневые события `SendInput` (система воспринимает ввод как нажатия реальной физической клавиатуры).
- **Режим IDE:** Автоматически устраняет дублирование автоотступов и закрывающихся скобок/кавычек в редакторах кода (VS Code, PyCharm, веб-песочницы).
- **Имитация человека:** Случайные микрозадержки между нажатиями и паузы на знаках препинания для естественного темпа.
- **Гибкая скорость:** От плавного ручного темпа до турбо-режима (>200 символов/сек).
- **Быстрая остановка:** Мгновенное прерывание процесса нажатием клавиши `ESC`.

## 🚀 Скачать и запустить

Установка не требуется — приложение поставляется в виде одного переносимого `.exe` файла.

1. Перейдите в раздел [**Releases**](../../releases).
2. Скачайте последнюю версию `AutoTyper.exe`.
3. Запустите файл (работает на Windows).

---

## 🛠 Как пользоваться

1. Вставьте нужный текст в окно программы.
2. Настройте скорость и нужные флаги (Режим кода / Имитация человека).
3. Нажмите кнопку **«🎯 Выбрать место и напечатать»** (окно свернется).
4. Кликните левой кнопкой мыши (ЛКМ) в поле, куда требуется ввести текст.
5. Если ввод нужно срочно остановить — нажмите **`ESC`**.
